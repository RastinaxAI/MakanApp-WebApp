مرجع کار web و طراحی نسخهٔ دوم است؛ فایل‌های ریشهٔ Vite، کارهای موجود و پنل جداگانهٔ مالک حفظ می‌شوند. بک‌اند سورس ندارد. بررسی OpenAPI فقط خواندنی است.

۱. مبنا: unit۱۴۷، build، typecheck و guest E2E موفق؛ lint موجود نیست و۸ اعلان بلااستفاده شناسایی شد.
۲. همهٔ تست‌های روزمره به backend محلی مستقل با منع شبکهٔ خارجی منتقل شوند؛ سوابق اجرای واقعی از گیت خودکار جدا ثبت شوند.
۳. route/role/token واحد، تفکیک پاسخ تکلیف و S09→S17→S10، حفاظت draft و receipt معتبر.
۴. رنگ و داک پایین تبلت V2، آیکن مستقل از hit target و صفحات مستقل فرم/بازبینی؛ بررسی۳۲۰/۳۹۰/۷۶۸/۸۳۴/۱۰۲۴/۱۴۴۰.
۵. حذف duplicate registry و CSS بلااستفاده با بررسی ارجاعات، حذف فقط cache/خروجی بازتولیدپذیر داخل web با manifest.
۶. نصب تمیز، تولید قطعی، lint/typecheck/unit/browser، CI و راهنمای توسعه؛ گزارش تمام محدودیت‌ها و موارد اجرا نشده.
