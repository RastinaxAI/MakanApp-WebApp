تصمیم جدید کاربر: به‌جای تقویم ماهانه، هفتهٔ شنبه تا جمعه با قبل/بعد و تاریخ هر دو سرِ بازه. ترجیحات با ردیف‌های هم‌اندازه و سه ستون مشترک لینک/دکمه. API و نقش‌ها تغییر نمی‌کنند؛ پذیرش با جلسات واقعیِ fixture، هفته‌های مجاور، خطای دریافت و retry، عبور نوروز/کبیسه، فوکوس و عرض‌های۳۲۰/۳۹۰/۸۳۴/۱۴۴۰ انجام می‌شود. محدودیت رابط اعلان/دستگاه مرحلهٔ قبل محفوظ است.
